Singing Oracle — install to M5 AtomS3 (Lite)

The Singing Oracle is a small ESP32 bridge that plays wordless choral melodies on an M5 Unit Synth in response to Home Assistant events. Each family member has a unique leitmotif; events like weather, packages, or the doorbell trigger short pitched phrases played on Choir Aahs (GM patch 53). See the project repository for design notes and firmware source.

Use Chrome or Edge on desktop. Web Serial is required. Safari and Firefox cannot flash the device from the browser.

This page never sends your device data to a remote service.
